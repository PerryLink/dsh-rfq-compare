# quickstart sample

- `input/quotes.csv` — synthetic 3 suppliers × 4 materials (12 quotes), generated by
  `node scripts/make-sample.mjs`. Amounts are integer cents; currencies are mixed
  (CNY / USD / EUR) so the placeholder FX path and all three anomaly classes are exercised.
  One note contains a comma and is quoted, which exercises the CSV parser.
- `input/assumptions.json` — the cost line, budget and `as_of` inputs used by the compare.
  Everything is CNY cents; no customer data.
- `expected/result.json` — the real stdout of `node samples/quickstart/run.mjs --json`.
- `run.mjs` — `--check` recomputes ingest + compare + export and diffs the result against the
  golden file; `--json` prints the golden payload; no flag prints a short summary.

Regenerate the sample and golden (after `pnpm build`):

```sh
node scripts/make-sample.mjs
node samples/quickstart/run.mjs --json > samples/quickstart/expected/result.json
node samples/quickstart/run.mjs --check
```

`docs/assets/quickstart.log` and `docs/assets/quickstart.png` are captured from the real
`--check` output; update `screenshots.json` hashes when they change.
